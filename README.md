# 🍔 Order.uk

> Plataforma completa de delivery de comida com carrinho de compras, filtros por categoria, carrinho lateral, múltiplos idiomas e design moderno.

🌐 **Website:** https://www.pablogdev.com.br  
🚀 **Demo:** https://pablog-7.github.io/orderuk-site-exemplo/

---

## 🎯 Sobre o Projeto

O **Order.uk** é um UI Concept de uma plataforma de delivery de comida desenvolvido para compor meu portfólio de desenvolvimento front-end. O projeto apresenta uma experiência completa para usuários que desejam pedir comida online, com sistema de carrinho de compras, filtros por categoria, carrinho lateral, busca por código postal, FAQ interativo e suporte a três idiomas (Português, Espanhol e Inglês).

Desenvolvido com HTML, CSS e JavaScript puro, este conceito demonstra a criação de plataformas de e-commerce food delivery com interface moderna e funcionalidades essenciais para conversão.

## ⚡ Funcionalidades

### 🏠 Página Inicial

- Hero com destaque para call-to-action
- Busca por código postal com feedback em tempo real
- Seção de ofertas exclusivas com até -40%
- Cards de restaurantes com imagem, desconto e preço
- Botão "Adicionar ao Carrinho" em cada oferta

### 🛒 Carrinho de Compras

- Carrinho lateral com animação suave
- Adição e remoção de itens
- Controle de quantidade (+ e -)
- Cálculo automático de subtotal
- Exibição do número de itens na barra superior
- Checkout simulado com mensagem de confirmação

### 🏷️ Filtros por Categoria

- Filtros: Todos, Vegano, Sushi, Pizza & Fast food, Outros
- Destaque visual do filtro ativo
- Exibição dinâmica dos cards filtrados

### ❓ FAQ Interativo

- Perguntas frequentes com expansão/colapso
- Ícone indicativo (mais/menos)
- Destaque visual da pergunta ativa

### 🌍 Multilíngue

- Suporte a 3 idiomas: Português, Inglês, Espanhol
- Seleção via seletor fixo no canto superior esquerdo
- Tradução de todos os textos da interface
- Mudança dinâmica sem recarregar a página

### 📱 Navegação Mobile

- Menu inferior fixo para dispositivos móveis
- Ícones com indicação de página ativa
- Navegação simplificada para telas pequenas

### 📨 Newsletter

- Formulário de inscrição com validação
- Feedback de sucesso/erro
- Integração simulada para coleta de leads

### 📊 Estatísticas

- Exibição de métricas: entregadores, pedidos, parceiros, itens
- Números animados com estilo moderno

## 🎨 Destaques do Design

- **Paleta Vibrante** - Laranja (#FF9800), azul escuro (#0b0b1c) e branco
- **Tipografia Moderna** - Poppins para toda a interface
- **Hero com Imagem** - Layout sofisticado com ilustração e cards flutuantes
- **Carrinho Lateral** - Experiência de compra fluida
- **Cards de Ofertas** - Imagem, desconto, nome e preço com hover suave
- **FAQ Animado** - Expansão suave com ícones dinâmicos
- **Seletor de Idioma Fixo** - Acesso rápido em qualquer lugar da página
- **Loading Inicial** - Animação de entrada com sweep effect
- **Responsividade** - Adaptado para todos os dispositivos
- **Scrollbar Customizada** - Estilização com tom laranja

## 💼 Sobre este Case

Este projeto faz parte da coleção de **UI Concepts** desenvolvidos para meu portfólio. O objetivo é demonstrar minha abordagem na criação de plataformas de e-commerce food delivery, com foco em design moderno, experiência do usuário e funcionalidades completas como carrinho de compras, filtros e sistema de tradução.

Caso deseje transformar este conceito em uma aplicação real, ele pode ser expandido com React, TypeScript, Next.js, backend, banco de dados, integrações com APIs de delivery, sistemas de pagamento e painéis administrativos.
